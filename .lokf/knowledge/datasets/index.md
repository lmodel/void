# Datasets

* [void LinkML schema](void-linkml-schema.md) - The LinkML schema of the Vocabulary of Interlinked Datasets (VoID), `src/void/schema/void.yaml` (schema id `https://w3id.org/lmodel/void`, version 2011-03-03): VoID's four classes and 27 properties under VoID's own names and IRIs, two partition classes of its own, and the Dublin Core, FOAF and RDF Schema terms a VoID description uses. Its `lokf adapt` copy `.lokf/void.yaml` is the bundle's domain schema.
* [Generated artefacts](generated-artefacts.md) - What `just gen-project` and `just gen-doc` generate from the void schema: the projections in `project/` (JSON Schema, JSON-LD, OWL, SHACL, ShEx, SQL, GraphQL, Protobuf, Excel, Java, TypeScript), the Python dataclasses and Pydantic models in `src/void/datamodel/`, the merged schema in `docs/schema/` and the schema pages in `docs/elements/`.
* [The schema's OWL rendering](owl-rendering.md) - `project/owl/void.owl.ttl`, the OWL ontology that gen-owl writes from the void schema, described as a VoID dataset: a Turtle file that w3id serves at `https://w3id.org/lmodel/void/void.owl.ttl`, using the OWL and RDF Schema vocabularies.
* [Example data](example-data.md) - The examples `tests/test_data.py` checks: valid records of every class in `tests/data/valid/` and `tests/data/problem/valid/`, and counter-examples in `tests/data/invalid/`, each naming in its first line, `# Fails at:`, where the validator must report it.
* [Upstream term lists](upstream-term-lists.md) - The two term lists in `tests/upstream/`, which `scripts/extract_void_terms.py` writes from pinned files: VoID's 31 terms with the domain, range, parent and functional facts of each, and the classes and properties of the five other vocabularies the schema names. `tests/test_upstream.py` holds the schema and its mappings to them.
* [Neighbours' adapt copies](neighbour-copies.md) - The thirteen released lmodel adapt copies in `tests/neighbours/`, each pinned by its SHA-256, against which `tests/test_schema_rules.py` holds this schema's copy: no shared class, and only the listed shared keys (`subject`, `comment`, `modified`, `label`, `seeAlso`).
