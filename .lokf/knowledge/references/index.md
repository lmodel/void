# References

* [Describing Linked Datasets with the VoID Vocabulary](void-note.md) - The W3C Interest Group Note of 3 March 2011 that explains the Vocabulary of Interlinked Datasets (VoID), by Keith Alexander, Richard Cyganiak, Michael Hausenblas and Jun Zhao, at `https://www.w3.org/TR/2011/NOTE-void-20110303/`, under the W3C Document License. The schema header pins it as its source.
* [VoID's vocabulary file](void-vocabulary-file.md) - The RDF Schema file that declares VoID's classes and properties, `rdfs/void.ttl` in the editors' repository cygri/void, pinned at commit `5b2ca68b7897` by its git object hash, since the namespace document at `http://rdfs.org/ns/void` redirects to a host that no longer answers. It states no licence.
